# EBITDA Bridge & Variance Analysis (FP&A Case Study)

A financial analysis project completed as part of an FP&A case study, focused on budget-vs-actual variance analysis for a fintech payments company.

## What I Built

- **Budget vs. Actual Variance Analysis** — monthly and full-year variances across Revenue, Gross Profit, OPEX categories, and EBITDA
- **EBITDA Bridge** — decomposed the full-year EBITDA gap into Revenue Shortfall, Gross Margin Compression, and OPEX overspend by category, with the bridge tying out exactly to actual EBITDA (zero rounding residual)
- **Growth Rate Analysis** — Month-over-Month (MoM) and Year-over-Year (YoY) revenue growth trends
- **3-Month Forecast** — Q1 forecast for revenue, gross profit, OPEX, and EBITDA, with explicit assumptions on growth rate, margin trajectory, and planned hires
- **Cost Optimization Recommendations** — quantified savings opportunities
- **Cash Runway Assessment** — burn rate analysis and credit facility recommendation

## Key Skills Demonstrated

- Variance decomposition methodology (isolating revenue effect vs. margin effect)
- Excel formula auditing and error correction
- Financial modeling and forecasting
- Data visualization (EBITDA bridge / waterfall charts, trend charts)
- Board-ready financial storytelling
